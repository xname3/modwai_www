Key Capabilities in Detail

Deep-dive into the features that make MODWAI the most comprehensive Oracle monitoring tool.

AI-Powered Execution Plan Analysis

Press one button and get a summary of what the query does, issues identified (full table scans, cartesian joins, memory problems), and top 3 actionable recommendations with expected performance impact.

  • 10+ detection algorithms automatically catch common Oracle performance anti-patterns
  • Color-coded plans — red for critical (full scans, cartesian joins), orange for warnings (sorts, nested loops), blue for info
  • 3 AI provider options: MODWAI Proxy (zero config), own API keys (GPT-4, Claude, DeepSeek, Gemini), or local Ollama (100% offline)

Session Recording

Like a flight recorder for your Oracle database. Samples active sessions at configurable intervals (0.5–10s) and builds a complete picture of activity.

  • Recording templates: Quick Check (1 min), Standard (5 min), Extended (15 min), Long Analysis (30 min)
  • Live dashboard: CPU vs Wait chart, top wait events, top SQL by activity, active sessions table
  • Data captured: session snapshots, wait histograms, SQL statistics, execution plans for top 100 SQL_IDs
  • AI analysis: one-click summary with bottleneck identification, root causes, and 3 specific recommendations

Real-Time Instance Dashboard

Visual overview of database health at a glance with interactive line, donut, and bar charts. Configurable auto-refresh intervals with historical data tracking.

  • CPU usage and trends — track utilization patterns over time
  • Memory utilization — SGA/PGA statistics, buffer cache, memory advisor
  • Disk I/O statistics — physical reads, writes, and redo log activity
  • Session & wait analysis — session count trends and wait event distribution

Health Check System

Automated database configuration analysis with AI-powered remediation recommendations. Get CRITICAL / WARNING / OK status indicators for common issues.

  • Pre-defined checks: archive log mode, parameters, backup status, license utilization, performance baselines
  • ASH activity analysis and AWR top SQL assessment
  • AI recommendations — detailed findings with step-by-step fixes
  • Average Active Sessions (AAS) monitoring for workload characterization

ASH & AWR Analysis

Full ASH/AWR analysis interface with 7 dedicated tabs for environments with Oracle Diagnostic Pack license. Deep historical performance analysis up to 8 days.

  • Real-time ASH — live V$ACTIVE_SESSION_HISTORY with filters by user, SQL_ID, and time range
  • AWR Snapshots — browse, compare two snapshots side-by-side, see delta statistics (DB time, CPU, commits, I/O)
  • Top SQL & SQL Analytics — sorted by elapsed time, CPU, buffer gets, disk reads, with performance trending charts
  • Blocking analysis — blocking chain visualization with durations and transaction IDs
  • AWR Reports — generate full HTML AWR reports directly from the app

Statspack Analysis

For environments without Diagnostic Pack, MODWAI provides Statspack-based performance analysis — an alternative to AWR that works on all Oracle editions including Standard Edition.

  • Snapshot management — browse, compare, and analyze Statspack snapshots
  • Top SQL identification — find resource-intensive queries by elapsed time, buffer gets, and disk reads
  • System statistics — DB time, CPU usage, I/O metrics, and wait event analysis between snapshots
  • AI-powered interpretation — automatic analysis of Statspack data with actionable recommendations

Frequently asked questions

Does MODWAI send my database data to the cloud?

Local AI via Ollama runs on your machine. If you use MODWAI Proxy, only execution plan metadata is sent, not raw database contents.

Do I need an Oracle Client installed?

MODWAI supports both Thin mode (no Oracle Client needed) and Thick mode (uses Oracle Instant Client for advanced features like TNS aliases).

Can I use my own AI API keys?

Yes. MODWAI supports OpenAI (GPT-4), Anthropic (Claude), DeepSeek, and Google Gemini with your own keys — unlimited usage, you pay per token directly to the provider.

What Oracle versions are supported?

Oracle Database 19c and higher, including RAC clusters and Pluggable Databases.
