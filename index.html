Before you connect

A few useful details.

For questions about your environment,
get in touch.

Which Oracle environments can I use?

MODWAI targets Oracle Database 19c and later and includes views for RAC and pluggable databases. Available reports and operations depend on the Oracle version, edition, container and account privileges.

Do I need Oracle Instant Client?

Basic connections use the driver's Thin mode without a separate Oracle Client installation. Thick mode is also available for connections that need Oracle Client features and requires a compatible client installation.

Does every feature need Diagnostics Pack?

No. MODWAI has its own session sampling and recording workflow. Statspack analysis is also available where Statspack is configured. Oracle ASH and AWR features are separate and require the appropriate Oracle Diagnostics Pack entitlement. Other Oracle operations may also have edition or licensing requirements.

What leaves my computer when I use AI?

Cloud AI receives the prompt and the diagnostic context included for that analysis, which may contain SQL, object names or diagnostic detail rows. MODWAI Proxy routes this through our backend; own-key connections send it to your provider. A locally hosted Ollama endpoint keeps inference local. Review your settings and prompts before sharing sensitive context.

Does MODWAI change my database automatically?

Monitoring reports read database information. SQL worksheets and administration tools can make changes when you run them with the necessary permissions. Data Pump, maintenance and OCI workflows provide command review steps; OCI also has optional immediate execution settings. AI responses are suggestions for you to review.

How do I activate a subscription?

After checkout, open Settings → Subscription in MODWAI. Enter the checkout email address, request a registration key and verify the emailed key in the app. Each subscription is for one user.
