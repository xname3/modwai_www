MODWAI Privacy Policy

MODWAI processes technical data necessary for Oracle database monitoring. The application does not collect personal data for marketing or for third-party distribution.

1. Data Processed

MODWAI may process:

  • database usernames,
  • SQL statements,
  • system logs,
  • performance metrics.

All processing occurs locally, unless the user activates external AI integrations.

2. Data Transfer

MODWAI does not transmit database data to third parties unless external AI integration features are enabled by the User.

3. Data Storage

The application does not store external copies of data unless explicitly enabled by the User.

4. Security

The User is responsible for protection of:

  • database accounts,
  • credentials,
  • environment configuration.

5. User Rights

The User may:

  • stop data processing by uninstalling the application,
  • disable AI integrations,
  • delete local logs.

6. Contact

For any privacy-related questions, please contact us at: hello@modwai.eu
